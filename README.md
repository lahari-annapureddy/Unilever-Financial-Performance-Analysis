# HUL Financial Performance Analysis

## Project Overview
This project analyses the financial performance of Hindustan Unilever Limited (HUL) using Microsoft Excel. It evaluates the company's 
financial position through key financial metrics and visualisations.

## Objectives
- Analyse revenue growth and profitability.
- Evaluate liquidity and capital structure.
- Examine operating cash flow trends.
- Present key financial insights and recommendations.

## Tools Used
- Microsoft Excel
- Financial ratio analysis
- Data visualisation and dashboarding

## Project Contents
- **HUL.xlsx:** Financial calculations, dashboard and insights.
- **Dashboard screenshot:** Visual summary of the analysis.

## Key Findings
The analysis examines changes in revenue, profitability, liquidity, debt levels and operating cash flow across financial years. Findings 
should be interpreted alongside the company's official annual reports.

## Data Sources
HUL's official annual reports and published financial statements. Verify all reported figures against the original sources before drawing 
conclusions.
